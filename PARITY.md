# Pulse vs a typical benefits platform (v4.1)

Benchmark: features advertised by Gusto (benefits admin), Nava Benefits (tech-enabled broker), Thatch (ICHRA platform), Take Command and Rippling/Justworks-style benefits modules. "Demo" = works end to end in Pulse with synthetic data. "Needs partner" = real-world integration we can't fake.

## Employee
| Feature | Typical platforms | Pulse |
|---|---|---|
| Enrollment wizard (new hire, open enrollment) | Gusto, Thatch, Nava | Demo: 5 steps, who is covered, needs, compare, extras, e-sign |
| Plan comparison and decision support | Nava, Thatch, Gusto | Demo: sorted by estimated yearly cost, "best for you", keeps-my-doctor check |
| Filter plans by your doctors | Thatch | Demo |
| Waive coverage with reason | All | Demo (reason kept private from employer) |
| Dependents and beneficiaries | All | Demo |
| Qualifying life events with proof, special enrollment | Gusto, all | Demo: report, upload, admin approval, 60-day window, allowance updates |
| Digital ID cards (medical, dental, vision) | Nava | Demo: flippable cards |
| Real-time deductible tracking | Nava | Demo (synthetic claims) |
| Find in-network providers | Nava | Demo |
| Cost estimates for services | Some (Nava via partners) | Demo |
| Bill review / advocacy | Nava | Demo: case intake and timeline |
| Year-round support / answers | Nava, Thatch | Ask Pulse (rule-based) plus advocates |
| HSA, FSA, commuter, 401(k), life, disability, EAP | Gusto | Demo: offered per employer config |
| Reimbursements and receipts | ICHRA admins | Demo, auto-approve under limit |
| Proof of individual coverage (ICHRA) | Thatch, Take Command | Demo: monthly, carrier check or upload |
| Documents: SBC, plan doc, notices, tax forms | All | Demo: generated, printable |
| Notifications and reminders | All | Demo: bell |
| Marketplace / card for leftover budget | Thatch (Thatch Market, Thatch Card) | Demo: wellness wallet and marketplace |
| Mobile app | All | Responsive web; native app not built |

## What Pulse has that they don't
Wellness rewards verified from wearables, private burnout alerts, team health signal with recovery week, status-aware goals, wellness wallet funded by results, "Pulse saved you" savings accounting, participation guarantee.
